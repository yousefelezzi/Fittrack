# Exercise images

Start and end position photos for FitTrack's built-in exercises come from
[Free Exercise DB](https://github.com/yuhonas/free-exercise-db) by yuhonas,
released into the public domain under the [Unlicense](https://unlicense.org/).
They were resized to 600 px wide. File names follow the FitTrack exercise
name: `<exercise-slug>-0.jpg` (start) and `-1.jpg` (end).

A few photos show the closest equivalent in that collection: T-Bar Row uses the
chest-supported (lying) T-bar row, Donkey Calf Raise uses the machine calf press.
